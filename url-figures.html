Important Figures

Tim Berners-Lee

Tim Berners-Lee is one of the most important figures in web design history as he was the first person to make a web server. Tim Berners-Lee made the first web server and client in 1989 and in 1994, he founded the World Wide Web Consortium where he served as it's director. He also served as director for the Web Science Trust in 2009 with each groups goal being to improve the system of web servers and pages whie also nurturing a fascination with web design. Tim Berners-Lee also made the World Wide Web, which is where the www comes from in the subdomain of the website URL. This allowed him to send information from one computer to another. See more of the www system in the Homepage in the Key Terms section. Tim Berners-Lee started out making web servers and procedded to build upon it, similarly to how wed deisgners build upon their websites. Tim Berners-Lee's accomplishments serve as the foundation of how all web designers should go about building websites.


Dr. Paul Mockapetris

Dr. Paul Mockapetris was another major factor in the development of the World Wide Web as he developed the DNS. The DNS serves as the main way that websites can differentiate from each other. Dr. Paul Mockapetris's DNS system is still used to this day though there has been improvements since then, the main principal and main layout used has remained the same. One of the major differences is the use of IP Addressed to help make sure that even if a website has a very similar name, they would still retain a unique IP Address that would differ from any other website.
