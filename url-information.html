URL and DNS

URL Basics

URLs are the main way that websites are able to be searched in the first place. URLs are also known as Uniform Resource Locators and are made up of different level domains. These domains serve as the foundation of which the search engines and the Internet rely on.


URL Domains

URLs are broken up into different sections called domains to help the computer track the website. Let's use https://www.google.com/search?q=example as an example. The https:// is the protocol and tells the computer what communication language is used to get the website. The www. is the subdomain which is used to seperate different parts of a website to make sure that the user gets to the correct location. The google part is the second-level domain and is used to identify the website and what it is meant to be. For example, www.HowToCookBrownie.com has the second level domain tell the user that the website is used to bake brownies, in a similar way to how www.google.com tells the user that the program will allow users to google information. The .com of the website is the top level domain and tells the computer what type of top level domain the website is in. the www.google.com together serves as the domain as a whole. The /search?q=example is the file and tells the computer what part of the website the user wants to pull up. Together, each piece of the URL works together to form the DNS, the Domain Name System.


DNS Basics

The DNS serves as the road that each website uses to find the website that the user is trying to access. We have already gone over how the URL system is broken down but we will now be going over how the system works together in a simplier way. We will be using https://www.google.com/search?q=example in this analogy. First, the computer looks at the https:// of the website so that they know the language to look in. This is the equivalent of looking at the language of the signs to make sure you are going the correct way on the road. Next, the computer looks at the .com / top level domain of the website to make sure that it checks the correct domain for the website. This is similar to how different cities can have locations with the same name even though they are different, to get to your location, you have to make sure you're in the correct city first. The next part is the second level domain which is the www.google part which tells the computer what website you want to go to. This is the equivalent of finding what building in the city you want to go to. You are telling your computer you want to head into the building, www.google to find your page. Then your computer looks at the file which tells your device what room the webpage is in. This is the /search?q=example which tells your computer to go into the search section of google and look up example. Every single computer in the world with Internet access do these types of calculations and pathfinding within a matter of microseconds to load even the smallest features on a website.
