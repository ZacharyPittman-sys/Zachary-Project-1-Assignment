Important Figures

Tim Berners-Lee

Tim Berners-Lee is one of the most important figures in web design history as he was the first person to make a web server. Tim Berners-Lee made the first web server and client in 1989 and in 1994, he founded the World Wide Web Consortium where he served as it's director. He also served as director for the Web Science Trust in 2009 with each groups goal being to improve the system of web servers and pages whie also nurturing a fascination with web design. Tim Berners-Lee started out making web servers and procedded to build upon it, similarly to how wed deisgners build upon their websites. Tim Berners-Lee's accomplishments serve as the foundation of how all web designers should go about building websites.


Dr. Paul Mockapetris

Dr. Paul Mockapetris was another major factor in the development of the World Wide Web as he developed the DNS. The DNS serves as the main way that websites can differentiate from each other. Dr. Paul Mockapetris's DNS system is still used to this day though there has been improvements since then, the main principal and main layout used has remained the same.
