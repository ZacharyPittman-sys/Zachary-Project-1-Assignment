Important Figures

  1. Tim Berners-Lee

    Tim Berners-Lee is one of the most important figures in web design history as he was the first person to make a web server. Tim Berners-Lee made the first web server and client in 1989 and in 1994, he founded the World Wide Web Consortium where he served as it's director. He also served as director for the Web Science Trust in 2009 with each groups goal being to improve the system of web servers and pages while also nurturing a fascination with web design. Tim Berners-Lee also made the World Wide Web, which is where the www comes from in the subdomain of the website URL. This allowed him to send information from one computer to another in a uniformed format that made accessing different sites easier than it had been before. See more of the www system in the Homepage in the Key Terms section. Tim Berners-Lee started out making web servers and procedded to build upon it, similarly to how web deisgners build upon their websites. Tim Berners-Lee's accomplishments serve as the foundation of how all web designers should go about building websites.


  2. Dr. Paul Mockapetris

    Dr. Paul Mockapetris was another major factor in the development of the World Wide Web as he developed the DNS. The DNS serves as the main way that websites can differentiate from each other. Dr. Paul Mockapetris's DNS system is still used to this day though there has been improvements since then, the main principal and main layout used has remained the same. One of the major differences is the use of IP Address to help make sure that even if a website has a very similar name, they would still retain a unique IP Address that would differ from any other website.

History of URL

The Internet was brought about when the government released their project to the world that they managed to link multiple computers together. The main downside with this system is that there wasn't a clear format in place which made accessing different websites difficult. Then, in 1983, Dr. Paul Mockapetris created the DNS system to make it where websites had a set format that made websites readable. This still had the problem of computers not being able to host websites for other computers to use which is where Tim Berners-Lee began working. In 1989, Tim Berners-Lee managed to create the World Wide Web and connected two computers together through an Internet connection. This also led to the creation of URL's which served as a way to interact with other computers through links. The URL also brought with it HTTP and HTML which helped solidify the method of linking devices and the World Wide Web has become a central part of devices to this day. As much as computers change and we develop more technological innovations, URLs continue to remain the same with only some changes for security and better formatting.
