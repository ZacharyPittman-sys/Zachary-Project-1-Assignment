Key Topics and Vocabulary

Structure Absolute URL Relative URL Top Level Domain Website
URLs are broken up into three main parts, subdomain, domain, and top level domain. The subdomain tells the computer that the website is part of the World Wide Web, thought this part is optional as computers assume that it's on the World Wide Web to begin with. The domain is a unqiue name for a website that is used by developers to make sure that the user knows what website they are heading to. the top level domain tells the website what type of website the computer should look for, this includes .org, .com, .edu, and more. URLs that contain the full web address like https://www.google.com. URLs that do not contain the full web address like /search?q=example when using https://www.google.com/search?q=example as an example. Top level domain is used to tell the computer what type of website the computer needs to look for. An example is .org being used to represent an organization's websites. Another example is .edu being used to represent an educational website. A website is a collection of web pages, applications, and more under a common name and serve a shared purpose. An example is how you can go to coolmathgames.com and be on the home menu but you can enter a different webpage through a link to access the games. The games are not contained to the homepage but instead are on different webpages connected to a single website.
